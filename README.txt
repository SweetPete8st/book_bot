OllieTrack — one-click Netlify Drop deploy

1. Download the zip (ollie-track.zip)
2. Unzip it (you will get a folder named "ollie-track")
3. On any device open: https://app.netlify.com/drop
4. Drag the entire "ollie-track" folder onto the page
5. Netlify instantly gives you a live HTTPS link (something like random-name.netlify.app)
6. Open that link on your phone → Allow Motion & Location when prompted
7. Optional: tap Share → Add to Home Screen for full-screen app feel

That’s it. No account required for the drop. The site is fully offline-capable after the first load.

Tips for best ollie detection:
- Phone in a tight front or side pocket works best
- Start with Sensitivity at 1.0, raise it if soft ollies are missed, lower it if curbs/walking trigger false counts
- Keep the browser tab open and screen on while skating
